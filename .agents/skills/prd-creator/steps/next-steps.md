# Next steps

The last section of the PRD tells the client what happens next and what is asked of them. Assemble it from what the interview already settled; don't open new questions here.

Draw the bullets from:

- **The joint review.** This one always comes first: "Review these requirements alongside the prototype, before any page is built. What you approve is what we build."
- **Anything awaiting the client's sign-off** that surfaced in the interview, such as a change against the proposal they have to confirm.
- **The client's time commitment** from `_project_/0-intake/proposal.md` ("What I'll need from you"), with the heavy points named: this review, user acceptance testing, cutover.
- **Access and data** the client must supply: workspace access (and capacity or Pro licences for readers), credentials for the source system held by the client's data owner, the list of readers and any row-level security rules, and any source data still missing from `_project_/1-discovery/data/`. Name the person who owns each where known, and when it is needed by.
- **Open questions** from `_project_/1-discovery/open-questions.md` that the interview could not close and that the client has to answer.
- **Validation**: someone on the client's side checks each page's numbers against a report they already trust, as each milestone lands.
- **Handoff**: the walkthrough near the end, so running the report, its refresh and its access list does not depend on JMS Analytics.

Propose the list in chat and use AskUserQuestion to confirm (looks right / I'll edit in chat).

Format rule for the client-facing copy: **every item is a bullet.** No intro paragraph, no narrative mixed with bullets, no callout banner. One action per bullet, written as something the client does or can expect.
